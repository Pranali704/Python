Data Member :
1)Instance Data Member a.Declared using self.
                       b.Each object gets its own copy
                       c.Changes in one object do not affect other objects.

2)Class Data Member: a.Declared inside the class but outside methods.
                     b.Shared by all objects of the class.
                     c.Only one copy exists.

3)Private Data Members: a.Begin with double underscore(_)
                     b.Cannot be directly accessed outside the class
                     c.Used for data hiding and encapsulation.
