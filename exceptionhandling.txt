EXECPTION HANDELING AND MULTITHREADING

Exception
an exception is an error that occurs during program execution, exception handeling allows a program to continue running without crashing unexpectedly
Common exceptions :
Zero division error
Value error
Name error
Index error
File not found error
Type error
Exceptions are called using a TRY block
Exception handling is done in the EXCEPT block
The ELSE block is executed for normal behaviour
The FINALLY block is executed regardless of the result of the try and except blocks
